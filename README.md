## O que é este workflow

Descrição organizacional completa do processo de transcrição de documentos
PDF regulatórios em arquivos Markdown estruturados, auditáveis e reutilizáveis.

Este repositório é a **memória organizacional** do processo — responde por que
ele existe, quem o usa, quais etapas envolvem automação e quais ainda são manuais,
e acumula o histórico de todas as execuções realizadas.
